Connect your GitHub account

You need a Personal Access Token (PAT) to trigger workflows. It stays in your browser and is sent only to the GitHub API.

1
Go to GitHub → Settings → Developer settings → Fine-grained personal access tokens and click Generate new token.
2
Fill in the token details:
Token name       OCHA FTS Trigger
Resource owner  your own GitHub username
Expiration       90 days (or custom)
3
Under Repository access, choose Only selected repositories, then select jayasekhon/OCHA_API_FETCH.
4
Scroll to Permissions. Click Repository permissions to expand it, find Actions in the list, and set it to Read and write. No other permissions are needed.
Actions         Read and write ✓
Everything else No access
5
Click Generate token, then copy the token that appears (it starts with github_pat_) and paste it below. You only see it once.
Your token is saved in your browser only — it is never sent anywhere except directly to the GitHub API to verify and trigger workflows.
