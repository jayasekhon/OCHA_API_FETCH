Setup Guide
STEP 1 — CREATE A PAT

Go to GitHub → Settings → Developer settings → Fine-grained tokens and click Generate new token.

Token name:
OCHA FTS Trigger
Resource owner:
jayasekhon
Repository access:
Only selected → OCHA_API_FETCH
Permissions needed:
Actions: Read and write ✓
STEP 2 — STORE YOUR TOKEN HERE

Paste the token into the Authentication field at the top of this page and click Save token. It is stored in your browser's localStorage — it never leaves your device except to call the GitHub API directly.

STEP 3 — SHARE THIS PAGE

Host this file on GitHub Pages (enable it under Settings → Pages → Deploy from main branch) or share the raw HTML file. Each user needs their own PAT — they create one following Step 1 and save it in their own browser.
