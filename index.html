Connect your GitHub account

You need a Personal Access Token (PAT) to trigger workflows. It stays in your browser and is sent only to the GitHub API.

1
Go to GitHub → Settings → Developer settings → Fine-grained tokens and click Generate new token.
2
Set Repository access to Only selected repositories → jayasekhon/OCHA_API_FETCH.
Under Permissions, set Actions → Read and write.
The resource owner should be your own GitHub username.
3
Copy the generated token and paste it below.
Your token is stored in your browser's localStorage only — it never goes anywhere except directly to the GitHub API to verify your access.
